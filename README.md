# Portfolio website

A single-page personal portfolio (`index.html`), with no build step and no dependencies.

**To customize:** open `index.html` and edit the `PROFILE` object near the top: name, school, projects, skills, links. The whole page updates from it.

**To publish free on GitHub Pages:** go to repo Settings → Pages → Source: "Deploy from a branch", then pick this branch and `/ (root)`.
